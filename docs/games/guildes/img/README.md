Images des guildes affichées sur l'écran de résultat.

Dépose ici un fichier par guilde, nommé d'après son identifiant :
azorius.svg, dimir.svg, rakdos.svg, gruul.svg, selesnya.svg,
orzhov.svg, izzet.svg, golgari.svg, boros.svg, simic.svg

Une guilde sans fichier garde le blason dessiné par défaut.
Pour un autre nom ou format (PNG, WebP), renseigne `symbol` dans ../data.js.
