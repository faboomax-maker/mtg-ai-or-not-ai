Images des guildes affichées sur l'écran de résultat.

Dépose ici un fichier par guilde, nommé d'après son identifiant :
azorius.webp, dimir.webp, rakdos.webp, gruul.webp, selesnya.webp,
orzhov.webp, izzet.webp, golgari.webp, boros.webp, simic.webp

Une guilde sans fichier garde le blason dessiné par défaut.
Pour un autre nom ou format (SVG, PNG), renseigne `symbol` dans ../data.js.
